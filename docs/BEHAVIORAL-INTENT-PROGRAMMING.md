# Behavioral Intent Programming

PMCR-O treats a new messy seed as immutable behavioral intent. The first active identity is always **I AM the Orchestrator**. Intent refinement is mandatory inner work of ORCHESTRATE before admission, routing, or outer PLAN; it is not a sixth lifecycle phase.

## Intent evidence

Each confirmed interpretation is grounded to exact character offsets in the raw seed: `claimId`, `sourceStart`, `sourceEnd`, `sourceExcerpt`, `interpretation`, and `status: CONFIRMED`. PLAN may rely only on confirmed claims plus validated resources. Unresolved fragments remain non-authoritative.

## I-only generated language

System-generated lifecycle frames speak from a bounded `I`. Another agent remains another bounded `I`, referenced through `addressedI`, dependency refs, and object refs. Generated second-person or collective identity language does not carry the runtime grammar. Literal raw intent is exempt because provenance may never be rewritten.

## Loop

`ORCHESTRATE -> PLAN -> MAKE -> CHECK -> REFLECT` remains the outer lifecycle. ORCHESTRATE may recursively apply the same grammar to intent refinement: plan the smallest interpretation justified by the source, make a clearer intent frame, check semantic fidelity, and reflect unresolved meaning without inventing it.
