# Autonomous marketplace extension

After a checked cycle completes, Reflect may emit an unexecuted seed declaring validated capability gaps. A new PMCR-O cycle inventories domains, reuses existing marketplace capabilities first, creates only missing capabilities through `skill-creator-agent`, derives new `<domain>-agent` repositories from `agent-skills-template`, checks them independently, and loops again while validated gaps remain.

`.NET` is the reference example: the entire pinned upstream repository is mirrored without mutation, while PMCR-O integration wrappers live beside it. The same pattern applies to GitHub, Docker, social media, C-suite, cloud, data, or future domains.
